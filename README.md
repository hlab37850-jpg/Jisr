# جسر (Jisr)

نقل ملفات آمن وسريع بين أجهزة Android بلا إنترنت.

## كيف يعمل
1. المرسِل يشغّل **LocalOnlyHotspot** ويعرض **QR** (SSID + كلمة المرور + المنفذ + مفتاح مشترك 256 بت).
2. المستقبِل يمسح QR، ينضم للشبكة عبر `WifiNetworkSpecifier`، ويتصل بـ TCP.
3. مصافحة: ECDH مؤقت (P-256) + المفتاح المشترك من QR → HKDF → مفاتيح AES-256-GCM لكل اتجاه + تأكيد متبادل (HMAC).
4. نقل مُعالَج بخطّي أنابيب (قراءة/تشفير/إرسال ثم استلام/فك/كتابة) بإطارات 256KB، مع SHA-256 لكل ملف يُتحقق منه قبل الاعتماد.

## البناء
ارفع المجلد إلى GitHub (فرع main) ← تبويب Actions ← Build Jisr ← حمّل Jisr-debug-apk.
الحد الأدنى Android 10 (API 29).

## غير منفّذ بعد
استئناف النقل بعد الانقطاع، تدفقات متوازية، خدمة أمامية للنقل مع إغلاق الشاشة، أيقونة التطبيق.
