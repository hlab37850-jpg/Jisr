# جسر (Jisr) v0.2

نقل ملفات آمن وسريع بين أجهزة Android بلا إنترنت.

## كيف يعمل
1. المرسِل ينشئ شبكة محلية: **وضع سريع** = مجموعة Wi‑Fi Direct بنطاق 5GHz مُجبَر (تجريبي)،
   ويرجع تلقائيًا إلى **LocalOnlyHotspot** إن فشل. ثم يعرض QR (SSID + كلمة المرور + المنفذ + مفتاح مشترك 256 بت).
2. المستقبِل يمسح QR، ينضم للشبكة عبر `WifiNetworkSpecifier`، ويتصل بـ TCP.
3. مصافحة: ECDH مؤقت (P-256) + المفتاح من QR → HKDF → AES-256-GCM لكل اتجاه + تأكيد متبادل (HMAC).
4. المستقبِل يرى قائمة الملفات ويوافق/يرفض قبل أي بيانات، مع فحص المساحة.
5. نقل بخطّي أنابيب (قراءة/تشفير/إرسال ثم استلام/فك/كتابة) بإطارات 512KB، وSHA-256 لكل ملف.
6. يعمل داخل **خدمة مقدمة** (إشعار تقدم + إلغاء) فيستمر مع إغلاق الشاشة أو الخروج من التطبيق.

## ميزات
مشاركة من أي تطبيق إلى جسر • سجل آخر العمليات • وضع داكن • ETA وسرعة حية • تقرير آخر عطل قابل للنسخ في الشاشة الرئيسية.

## البناء
ارفع المجلد إلى GitHub (main) ← Actions ← Build Jisr ← حمّل Jisr-debug-apk. الحد الأدنى Android 10.

## غير منفّذ
استئناف النقل بعد الانقطاع، تدفقات متوازية (ليست عنق الزجاجة عادة)، ضغط تكيّفي.
